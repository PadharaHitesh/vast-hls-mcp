Open-source MCP server · Video ad tech

vast-hls-mcp

Debug video ad delivery: decode SCTE-35 cues, find HLS ad breaks, inspect playlists and validate VAST ad tags. The same tools AI assistants like Claude call through the Model Context Protocol, running here directly in your browser.

  • Runs 100% in your browser: nothing you paste is uploaded
  • The real, tested Python package via WebAssembly (Pyodide)
View on GitHub Use it with Claude

Ctrl/⌘ + Enter to run Starting Python in your browser (first load takes a few seconds)…

Use it with Claude or any MCP client

In an AI assistant you just ask: “Why isn’t this ad tag filling?” or “Check the ad breaks in this stream.” The assistant picks the right tool, reads the structured result and explains it. The MCP server also fetches URLs (with SSRF protection) and follows VAST wrapper chains with unwrap_vast, which a browser can’t do because of cross-site (CORS) rules.

git clone https://github.com/PadharaHitesh/vast-hls-mcp.git
cd vast-hls-mcp && python -m venv .venv && source .venv/bin/activate
pip install -e .
claude mcp add vast-hls-mcp -- "$PWD/.venv/bin/vast-hls-mcp"
